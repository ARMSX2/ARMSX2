# Signed licence rules for the downloadable shader catalogue

The rules `shader_manifest.py emit` is built from. Without this file at this pin the
generator refuses and no manifest and no zip exist, which is the point of it: the
catalogue cannot physically be produced before someone has signed the rules behind it.

The evidence these rules were read against is regenerated by

    python3 platforms/ios/scripts/shader_manifest.py classify --checkout <slang-shaders at the pin>

into `platforms/ios/build-ios-shader-manifest/`, which is gitignored. The ballot there is
711 lines, the per-file evidence is 4,445 rows, and both are reproducible from the pin, so
they are not copied here. The hashes below are what make that reproduction checkable.
Two of them, because the same file is written twice: `classify` writes it with the verdict
column empty, which is the state it was read in to sign this, and `emit` rewrites it with
the verdicts these rules produce. The second is what the catalogue was built from.

    Signed-by: J1coding
    Signed-on: 2026-08-18
    Pin: 80372284ea8c00ae5e25e5a6e4f9f49415f85896
    Sample-size: 30
    Sample-size-NO_LICENCE: 10
    Evidence-SHA256: b40ebc2f4600523e9c7964329f85c33d7bb040ab1f8eb2558b4b871cb47ac02c
    Evidence-SHA256-before-verdicts: 45b10a33d4c5582fbd6c2403aa7273dd7acd9819046e8c3910a27854674ef934
    Config-max-bytes: 4096

## The class rules

| Class | Code | Files | Decision | Reason |
|---|---|---|---|---|
| P | PUBLIC_DOMAIN | 89 | include | the file states public domain or CC0 in its own text |
| M | PERMISSIVE | 175 | include | a complete MIT or BSD permission block is present, not just the name |
| G | GPL_OR_LATER | 402 | include | GPL naming a version and permitting later ones, so GPL-3.0 is reachable |
| Gv | GPL_VERSION_ONLY | 25 | include | see below |
| U | GPL_UNVERSIONED | 19 | include | see below |
| C | CONFIG_ONLY | 2252 | include | a header-less preset of key = value lines under the byte ceiling carries no authorship worth claiming |
| L | DIRECTORY_LICENCE | 175 | include | see below |
| N | NO_LICENCE | 1143 | exclude | the standing rule: silence is not a grant |
| X | UNCLASSIFIED | 165 | exclude | conflicting or unrecognised grants, refused until read one by one |

Six of these are confirmations of rules that already governed the bundled sixteen. Three
were open, and they are the reason this document exists.

### Gv, GPL naming a version with no "or later"

Twenty-five files, worth six presets on their own. The formal objection is real: ARMSX2 is
GPL-3.0-or-later and GPL-2.0-only is not compatible with GPL-3.0. What is being shipped is
not compatible-or-not code, though. A `.slangp` closure is data the app loads at runtime
and never links, compiles into itself or derives from, and it is served as its own archive
with its own licence text intact. Admitted on that basis.

### U, a GPL keyword with no resolvable version

Nineteen files, and this class already has precedent. `crt-aperture` and `crt-easymode`
are class U, they were overruled in by hand for the bundle on 2026-08-16, and that
judgement was recorded when they were bundled. Admitting the class generalises a
decision already taken twice rather than making a new one.

### L, a LICENSE file governing a parent directory

This is the one with the least precedent and the largest effect. Refusing it caps the
catalogue at 244 presets; admitting it takes it to 866. It is also exactly the inference
the standing rule exists to refuse: nothing is read from a sibling file, only from the
file itself.

Admitted, for a reason narrower than the rule it bends. slang-shaders is one repository
under one project licence, and a per-directory LICENSE in it is how that project states
the terms for the work beside it — `crt-royale` and `crt-beans` both do this. Treating a
directory's own LICENSE as silent is not caution, it is refusing to read the only
statement the author made. The rule stays as written for anything outside a licence file's
own directory tree.

Under these rules the run offers **866 presets**. That number is an output of the rules,
not a target chosen first.

## Per-file overrides

Admitting generalises, so it is a class decision. Refusing does not have to generalise, so
it stays a file decision. Per-file admission belongs only in UNCLASSIFIED, which is refused
by default and read one row at a time.

| Path | Decision | Reason |
|---|---|---|
| handheld/shaders/lcd1x.slang | include | already read and settled by hand when the bundled set was audited |

`lcd1x.slang` states that the original lcd3x was released into the public domain and then
places jdgleaver's edit under GPL-2.0-or-later. The classifier sees two grants in one file
and refuses, correctly, because it cannot tell which one governs. A person can: both
statements are true of different things and the derived file ships under the GPL clause.

`lcd1x_nds.slang` and `lcd1x_psp.slang` carry the same shape of header and are **not**
overridden. Nobody has read them. Extending one file's judgement to two files nobody
opened is the inference this document spends three paragraphs refusing elsewhere.

## Modification sign-off

Serving a changed file makes ARMSX2 a redistributor of modified third-party work. GPL and
MIT both require the change to be marked, so the generator records every patched file with
its patch, its reason and both hashes, and the manifest carries that record.

| Patch | Files | What it changes |
|---|---|---|
| slang-shaders-prescale-zero-guard.patch | 2 | the two bundled files, clamped on 2026-08-17 |
| slang-shaders-catalogue-prescale-zero-guard.patch | 10 | twelve more prescale sites reachable only from the catalogue |

Both are signed off. The second is new with this document. Every clamp in it is
`max(<the author's own expression>, 1)` and nothing else: no behaviour changes above a
scale of one, which is every case RetroArch itself produces. Below one the upstream
expression divides by zero and the frame is black, so there is no working behaviour to
preserve there. Twelve sites and not ten because the scanner reports one site per file,
and clamping the first in `crt-potato` and `ultra_potato` made a second visible in each.

Refusing instead was the alternative and it costs 98 presets, including all six `crt-potato`
variants. It was rejected because the fix is the same one-line clamp already signed off for
the bundle, and because refusing would ship a catalogue whose omissions nobody could
explain.

## The CONFIG_ONLY byte ceiling

4,096 bytes, unchanged from the classify run. A header-less `.slangp` above the ceiling
falls to DIRECTORY_LICENCE or NO_LICENCE instead of qualifying as configuration.

| Ceiling | Header-less presets that qualify |
|---:|---:|
| 1,024 | 1,291 |
| 2,048 | 1,543 |
| 4,096 | 2,252 |
| 8,192 | 2,348 |
| 16,384 | 2,514 |
| none | 2,514 |

The test that matters is not the size, it is whether anyone would write the file
differently. A 92-byte `crt-geom.slangp` is three lines that anyone wiring that stage up
would write the same way. A 13 KB Mega_Bezel preset is still `key = value` lines, but it
carries authored prose in its comments and an arrangement of forty passes, which is a
weaker fit. 4,096 puts the boundary between the two.

## What is still refused, and what it would cost to change

| Refused | Presets it would return | What answering it needs |
|---|---:|---|
| class X, UNCLASSIFIED | not computed | 165 rows read one at a time |
| unresolved closure | 13 | an upstream fix for seven unterminated quotes; six are parameter fragments with no stage and should stay out |
| disallowed extension | 8 | `.hlsl` added to the extractor allowlist in ARMSX2Bridge.mm |

None of these is a defect in the generator. Each is a decision nobody has taken yet, and
each is cheap to revisit because the run takes fifteen seconds and needs no network.
